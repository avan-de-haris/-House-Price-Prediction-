How It Works

Full Pipeline Walkthrough

Every step is isolated in its own file but passes data cleanly to the next.

01

Load Dataset

Read 168,446 rows from the Zameen.com CSV. Print column list, dtypes, and missing value counts so you know exactly what you're working with before touching the data.

📄 data_loader.py → load_data()
02

Data Cleaning

Filter For Sale listings only → remove price outliers (1st–99th percentile) → keep only Marla area type → cap bedrooms and baths at 1–15 → drop 9 irrelevant columns → final shape: 77,027 rows.

📄 preprocessing.py → clean_data()
03

Feature Engineering

Label-encode 5 categorical columns. Select 10 features. Separate feature matrix X from target vector y (price).

📄 preprocessing.py → encode_features()
04

Train / Test Split

80% training (61,621 samples) and 20% testing (15,406 samples). StandardScaler applied separately for Ridge Regression to avoid data leakage.

📄 model_training.py → split_data()
05

Individual Model Training

Three algorithms: Ridge Regression (linear baseline), Random Forest (100 trees, depth 15), and Gradient Boosting (200 estimators, lr 0.1).

📄 model_training.py → train_individual_models()
06

Ensemble Learning

Voting Regressor — averages RF and GB predictions. Stacking Regressor — RF + GB as base learners, Ridge as meta-learner via 3-fold CV.

📄 model_training.py → train_ensemble_models()
07

Evaluation & Comparison

Side-by-side metrics table: MAE, MSE, RMSE (in PKR millions), and R² for all 5 models. Best model identified automatically.

📄 evaluation.py → print_summary()
08

Visualisations

5 publication-quality PNG charts saved to the outputs/ folder: EDA, model comparison, actual vs predicted, feature importance, residuals.

📄 visualisation.py → generate_all()

Getting Started

How to Run the Project

Clone the folder, install dependencies, and run one command.

terminal — install dependencies
# Install required libraries
pip install scikit-learn pandas numpy matplotlib seaborn flask
terminal — run Flask web app
# Start the Flask server (Dashboard + Predictor)
python app.py

# Then open in browser
http://127.0.0.1:5000

# OR run the full ML pipeline first to generate charts
python main.py
app.py — add this route to serve chart images
from flask import send_from_directory

# Add this route so /outputs/ images load in the dashboard
@app.route('/outputs/<path:filename>')
def serve_outputs(filename):
    return send_from_directory('outputs', filename)
